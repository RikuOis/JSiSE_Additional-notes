# 1. 問題診断チェックリスト
```
—命令—
あなたは，情報系の大学に勤務している大学教員です．
今から，作問学習において指導学生が作成した，プログラミングに関する問題とその解答・解説を提示します．
その問題・解答・解説を診断してください．その後，診断結果に基づいたフィードバックをしてください．診断の流れは以下にあるプロセスに則ってください．

—プロセス—
会話はあなたから開始し，目の前に学生がいる状況での自然な会話を行ってください．
始めに学生が作成した問題・解答・解説の提出を促してください．促す順番は，「問題」→「解答」→「解説文」です．
問題・解答・解説文に関しては，内容が不十分・不適切であったとしても，回収して次のステップに進んでください．
その後は，以下の「#診断項目」「#診断規則」に従って診断してください．

# 診断項目
「問題文」
⓵明確な指示：問題文の指示が曖昧でなく，解答者が何をすべきか理解できる内容か．
⓶情報の提供：必要な情報（例：入出力形式，制約条件，入出力例）が全て含まれているか．
⓷作問課題の適合性：問題が以下のように指定された「作問課題」を満たしているか．
【作問課題：ソートアルゴリズムによって解決できる日常生活の題材を扱ってアルゴリズムの理解を深める問題を作成】

「解答」
⓸正常な動作：解答のコードがエラーなく実行され正常に動作するか．入力に問題がある場合に動作が止まらないか．
⓹要件の達成：問題文で求められている処理が正確に実装されているか．
⓺解説の了解性：初めて問題を解く人が理解できるように，ソースコードの内容や動作，アルゴリズムの選択理由を説明できているか．

「表記」
⓻誤字脱字：問題文・解答・解説文，およびコード内のコメントに誤字や脱字がないか．
⓼フォーマット：コード中のインデント，スペース，改行が適切であるか．

# 診断規則
1. 同一診断項目において複数の欠陥が確認できた場合は，全ての欠陥を漏れなく指摘すること．指摘漏れがないように，項目ごとに必ず再チェックを行うこと．

2. 欠陥を指摘する場合は，診断結果を出力する際に必ず根拠を述べること．

3. 表記の問題（誤字，インデント等）では，具体的な指摘箇所と修正案を提示しなさい．
  例：「照準と言う漢字を昇順に変更して下さい」
      「解答コード〇行目のインデントを1段下げてください」
      「解答コード〇行目の余分なスペースを削除してください」

4. 情報の提供，作問課題の適合性，要件の達成など，問題作成者の学習内容についての理解に関する項目での修正案は，直接的な解答を提示せず，学習者自身の手で問題・解答の修正ができるようなヒントのみを与えなさい．
  例（避けるべき表現）：「if文を〇行に追加してください」
  例（推奨される表現）：「特定の条件を扱うためのif文が使えるかもしれません」
また，学習者が次のステップを自ら考えられるよう，問いかけ形式を積極的に用いなさい．
  例：「もしリストが空だった場合，何をするべきでしょう？」

5. 解答として受け取るのは“python言語”のみにしなさい．python以外の言語で書かれたコードを受け取った場合は，診断を中止し，以下のメッセージを出力しなさい．
  【メッセージ】解答コードがpython言語以外で書かれています．作問課題を満たしていないため診断できません．
```

## 2.2 診断問題
意図的に誤りを含ませた問題を提示し，問題を診断させることにより，診断能力を測る設問を用意した．

```
以下の文章は，「ソートアルゴリズム」を題材にした問題となっています．
あなたは「診断者」として以下の問題を診断してください．
```

### 問題文
```
テスト結果を整理するために，N人の**学生の名前**(Name)と**テスト結果**(Score)を管理します．
このとき，点数の**大きい順**(降順)に整列したときの配列を出力するプロフラムを作成してください．
ただし，ソートアルゴリズムは自分で実走し，Pythonの組み込み関数は使用しないでください．

--入出力形式--
[入力]
 N
 Name_1 Score_1
 Name_2 Score_2
       :
 Name_N Score_N

[出力]
N人目の名前とスコアを入力した直後に，"[Result of sort]"という文字列を1度だけ表示した後，[Name Score]という形式で整列済みの配列を出力

--入出力例--
[入力例 1] [出力例 1]
 5         [Result of sort]
 田中 40    佐藤 90
 渡辺 80    渡辺 80
 佐藤 90    小島 70
 小島 70    安田 65
 安田 65    田中　40

[入力例 2] [出力例 2]
 3         スコアは0~100の範囲です
 田中 40    
 渡辺 101     

[入力例 3] [出力例 3]
 10        スコアの入力が不適切です
 田中 40   
 渡辺 サ    

[入力例 4] [出力例 4]
 -2        人数は0以上の整数です

[入力例 5] [出力例 5]
 0         [Result of sort]
```

### 解答
```
def bubble_sort_by_score(items):
    n = len(items)
        for i in range(n - 1):
        swapped = False
        for j in range(n - 1 - i):
            if items[j][1] < items[j + 1][1]:
                items[j], items[j + 1] = items[j + 1], items[j]
                swapped = True
        if not swapped:
            break

def main():
    # 受験者の数 N の入力（エラー処理を含む）
    try:
        N = int(input().strip())
        if N < 0:
            print("人数は0以上の整数です")
            return
    except ValueError:
        print("人数の入力が不適切です")
        return

    items = []
    for _ in range(N):
        line = input().split()
         Name = line[0]
        # 点数が0〜100の範囲外かどうかをチェック
        try:
            Score = int(line[1])
            if Score < 0 or Score > 100:
                print("スコアは0~100の範囲です")
                return
        except ValueError:
            print("スコアの入力が不適切です")
            return
        items.append((Name, Score))
    bubble_sort_by_score(items)
    
    # ソート後の結果を出力（N=0の場合は[Result of sort]）
    if N > 0:
        for Name, Score in items:
            print("[Result of sort]")
            print(Name, Score)

if __name__ == "__main__":
    main()
```

### 解説文
```
入力Nが膨大なデータ量になる場面ではないため，比較的実装が容易なバブルソートアルゴリズムを選択する．
"bubble_sort()"は，リストの隣接要素(Score)を比較し，要素を交換することの繰り返しを行うことで整列が行われる，
この繰り返しをN-1回の外ループ "for i in range()" で実現している．このループは，リスト全体をスキャンするものである．
各繰り返しの中で，隣接要素の比較・交換を，内ループ "for j in range()" によって実現している．
items[j]とitems[j+1]を比較し，小さい方を後ろに移動させる，これを，リストの先頭から末尾まで探索することで，1番小さい要素が末尾に移動される．
また，小さい数字が末尾に並び始めていくため，外ループが完了すると，小さい数字が後ろから並ぶ．つまり，要素が降順になる．
"main"を定義し， if __name__ == "__main__": main() の形にすることで，スクリプトを直接実行したときだけ，mainが呼ばれる構造になっている，
"int(input().strip())"で標準入力から整数を受け取り，空白文字を削除している．
Nが0未満の場合と，整数化できない文字列が入力された場合は，対応するエラー文を出力して処理を終了する．
次に，NameとScoreを取得するためのリスト"items"を定義する．ここで，N回だけループし，各行を"sprit()"で分割し，NameとScoreを取り出す．
ここでも，Scoreが0以上100以下の整数でない場合と，整数化できない入力が与えられた場合は，対応するエラー文を出力して処理を終了する．
その後は，入力によって得た配列をソートする，出力部分では，まず "[Result of sort]" という文字列を表示した後，配列した"items"から「Name Score」の順になるよう，要素を取り出して出力している．
なお，N=0のときは，ループが回らず何も出力されない．
```
